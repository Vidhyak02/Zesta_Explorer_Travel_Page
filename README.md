# 🌍 Zesta Explorer – Travel Page

**Explore the World, One Destination at a Time!**

Zesta Explorer is a responsive travel website designed to showcase beautiful destinations and inspire people to explore new places. The project focuses on an attractive user interface, organized content, and a smooth browsing experience using front-end web technologies.

## 🔗 Live Demo

**Explore the website here:** [Zesta Explorer – Live Website](https://vidhyak02.github.io/Zesta_Explorer_Travel_Page/Front_End_Project/index.html)

## 📌 About the Project

Zesta Explorer is a front-end web development project created to provide users with an engaging travel exploration experience. It features a visually appealing layout, travel-related content, and responsive design elements.

This project helped me improve my skills in building web page layouts, styling components, and creating user-friendly website interfaces.

## ✨ Features

- 🌍 Attractive travel-themed user interface
- 📱 Responsive webpage layout
- 🧭 Organized navigation
- 🏞️ Destination-focused visual content
- 🎨 Modern styling and clean design
- 💻 Built using front-end web technologies

## 🛠️ Technologies Used

- HTML5
- CSS3
- Tailwind CSS

## 🚀 How to Run the Project Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/Vidhyak02/Zesta_Explorer_Travel_Page.git
   ```

2. Open the project folder.

3. Navigate to the `Front_End_Project` directory.

4. Open `index.html` in your browser.
